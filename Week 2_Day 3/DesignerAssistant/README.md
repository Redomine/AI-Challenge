# Помощник проектировщика, день 8

Минимальный консольный агент на .NET 8. Он принимает сообщения проектировщика,
передаёт их модели через GigaChat API и сохраняет контекст диалога в SQLite.
После перезапуска приложения история загружается обратно. Для каждого ответа
приложение показывает расход токенов, заполнение контекста и оценку стоимости.

## Что реализовано

- отдельный класс агента `DesignAssistantAgent`;
- отдельная абстракция LLM-клиента `ILlmClient`;
- HTTP-клиент для GigaChat API с OAuth-авторизацией без сторонних NuGet-пакетов;
- системная инструкция для помощника проектировщика ОВ и ВК;
- история сообщений в оперативной памяти;
- сохранение сообщений пользователя и помощника в SQLite;
- автоматическое восстановление истории при запуске;
- подсчёт текста через официальный endpoint `POST /tokens/count`;
- чтение фактического расхода из объекта `usage` ответа GigaChat;
- счётчики текущего сообщения, истории и ответа модели;
- заполнение контекстного окна и предупреждение о приближении к лимиту;
- оценка стоимости запроса и накопленной стоимости текущего запуска;
- команды `/help`, `/clear` и `/exit`;
- обработка отмены, сетевых ошибок и ошибок API;
- конфигурация через переменные окружения.

Компрессия и автоматическое усечение истории намеренно не выполняются: для дня 8
важно увидеть, что произойдёт при реальном переполнении контекста.

## Требования

- .NET SDK 8.0 или новее;
- ключ авторизации GigaChat;
- доступ к выбранной модели.

## Настройка в PowerShell

```powershell
$env:GIGACHAT_AUTH_KEY = "ваш-ключ-авторизации"
$env:GIGACHAT_SCOPE = "GIGACHAT_API_PERS"
$env:GIGACHAT_MODEL = "GigaChat-2"
dotnet run --project .\DesignerAssistant.csproj
```

Не записывайте настоящий API-ключ в исходный код или репозиторий.

Дополнительные настройки:

```powershell
$env:DESIGN_ASSISTANT_MAX_OUTPUT_TOKENS = "1200"
$env:DESIGN_ASSISTANT_DB_PATH = ".\designer-assistant.db"
$env:GIGACHAT_CONTEXT_LIMIT_TOKENS = "128000"
$env:GIGACHAT_PRICE_PER_MILLION_TOKENS = "65"
$env:GIGACHAT_TOKENIZER_MODEL = "GigaChat"
```

`GIGACHAT_SCOPE` можно не задавать: по умолчанию используется
`GIGACHAT_API_PERS`. OAuth-токен запрашивается автоматически и обновляется до
истечения срока действия.

`GIGACHAT_TOKENIZER_MODEL` задаёт модель для `/tokens/count`. По умолчанию
используется поддерживаемый токенизатор `GigaChat`; он может отличаться от
алиаса модели генерации `GigaChat-2`.

Если `/tokens/count` возвращает `404` для доступной модели, приложение не
прерывает диалог: оно оценивает текст из расчёта 3,5 символа на токен и отмечает
такие значения знаком `≈`. Токены ответа и тарифицируемый расход при этом
остаются фактическими значениями из `usage` ответа модели.

Значения лимита и цены зависят от модели и тарифа. По умолчанию в учебном
примере используются окно 128 000 токенов и цена 65 рублей за миллион токенов
для `GigaChat-2`. Перед расчётом реальных расходов сверяйте тариф GigaChat.

## Проверка

После запуска можно провести короткий диалог:

```text
Вы: В этом проекте шаг креплений воздуховодов принят равным 2 м. Запомни.
Помощник: Принял.

Вы: Какой шаг креплений принят в проекте?
Помощник: 2 м.
```

Завершите приложение командой `/exit`, запустите его снова и задайте второй
вопрос. Агент загрузит прежние сообщения из `designer-assistant.db` и продолжит
диалог с учётом ранее принятого решения.

Команда `/clear` удаляет историю как из памяти, так и из SQLite. Путь к базе
можно изменить через `DESIGN_ASSISTANT_DB_PATH`.

## Эксперименты с токенами

Короткий диалог: выполните `/clear`, затем задайте два коротких вопроса. Число
токенов истории будет небольшим, но второй запрос уже включает первую пару
сообщений.

Длинный диалог: попросите несколько раз подготовить подробный текст или вставьте
крупные фрагменты документа. Поле `история после ответа` растёт, а вместе с ним
растёт контекст каждого следующего запроса.

Для безопасной демонстрации предупреждения не требуется отправлять 128 000
токенов. Перед запуском временно задайте учебный лимит:

```powershell
$env:GIGACHAT_CONTEXT_LIMIT_TOKENS = "2000"
dotnet run --project '.\DesignerAssistant.csproj'
```

Запускайте команды из папки `Week 2_Day 3\DesignerAssistant`. После нескольких
развёрнутых ответов приложение покажет предупреждение. Это демонстрация
локального порога; фактический API продолжит работать, пока не будет превышено
реальное окно выбранной модели.

При переполнении сумма системного промпта, истории, нового сообщения и резерва
ответа не помещается в контекстное окно. Приложение до отправки покажет размеры
контекста, лимит и превышение, затем отклонит весь запрос. История специально не
усекается, чтобы это поведение было видно в рамках задания.

Переполнение контекста не следует путать с `finish_reason=length`. Во втором
случае запрос поместился, но модель израсходовала `max_tokens` при генерации:
ответ уже получен, однако его конец обрезан. Консоль выводит эту причину отдельно.
