# Техническое задание для Codex: день 6

## Цель

Создать минимального консольного агента «Помощник проектировщика», который ведёт
диалог с пользователем через LLM API. Агент должен быть самостоятельным классом,
а не набором запросов из `Program.cs`.

## Функциональные требования

1. Приложение запускается из консоли и принимает текст пользователя.
2. Агент отвечает как помощник проектировщика ОВ и ВК.
3. Агент хранит историю только во время текущего запуска.
4. Сообщения текущего диалога передаются модели при каждом запросе.
5. Команда `/clear` очищает историю.
6. Команда `/exit` завершает приложение.
7. API-ключ, адрес API и модель задаются через переменные окружения.
8. Ошибки API выводятся пользователю без аварийного завершения цикла диалога.

## Архитектурные требования

- целевая платформа: .NET 8;
- `Program.cs` отвечает только за конфигурацию и консольный интерфейс;
- логика агента находится в `DesignAssistantAgent`;
- обращение к модели скрыто за `ILlmClient`;
- системная инструкция вынесена в отдельный класс;
- сторонние NuGet-пакеты на этом этапе не используются;
- секреты запрещено хранить в репозитории.

## Не входит в день 6

- SQLite и восстановление истории после перезапуска;
- подсчёт токенов и стоимости;
- обработка переполнения контекстного окна;
- компрессия истории;
- вызов инструментов и изменение BIM-моделей;
- графический интерфейс.

## Критерии приёмки

- проект собирается командой `dotnet build`;
- без API-ключа приложение сообщает, какая переменная не задана;
- пользователь может провести диалог минимум из двух связанных сообщений;
- модель учитывает первое сообщение при ответе на второе;
- `/clear` очищает историю текущего запуска;
- сетевой сбой или ошибка API отображается понятным сообщением;
- `Program.cs` не содержит прямой сериализации запроса к LLM.
